# План разработки проекта: Wall Printer (Фаза 3: Frontend)

## Описание
Мы завершили сбор требований, анализ аудиторий (AJTBD), структуру сайта (SITE.md) и визуальную часть (DESIGN.md). На основе этих артефактов мы приступаем к разработке самого сайта (лендинга).

## Proposed Changes

### 1. Инициализация проекта [NEW]
- Создание проекта через `npm update` / Vite (React+TypeScript).
- Установка Tailwind CSS и настройка фреймворка.
- Установка вспомогательных библиотек (framer-motion для анимаций, lucide-react для иконок).

### 2. Подготовка дизайн-системы (Внедрение DESIGN.md) [MODIFY]
- Настройка `tailwind.config.js`:
  - Интеграция шрифтов `Outfit` и `Inter`.
  - Цвета: `Primary (#0A0D14)`, `Surface (#151A27)`, `Neon Cyan (#00F0FF)`, `Electric Purple (#A855F7)`.
- Настройка глобальных стилей (сброс, скроллбар).

### 3. Верстка компонентов (Components Layer) [NEW]
- `HeroSection`: Видео-фон, заголовок с градиентом, Toggle B2C/B2B (В2G).
- `TrustBlock`: Триггеры доверия (Гарантия, экологичность) с glassmorphism.
- `FeaturesSection`: Отличие от художников и обоев.
- `SolutionClubBanner`: Выделение работы "Под ключ" от строительной компании.
- `Gallery`: Слайдер работ принтера.
- `PriceForm`: Блок с тарифами от 45 000 руб и формой захвата.

### 4. Сборка страниц [NEW]
- Интеграция всех компонентов на `App.tsx`.
- Настройка логики Toggle (при переключении B2B/B2C меняются офферы и фоны в HeroСекции).
