# Рекомендации по старту проекта "Wall Printer"

Для успешного запуска проекта и эффективной работы агентов (памяти) рекомендуется следующее:

## 1. Настройка окружения
- **Node.js**: Убедитесь, что установлена LTS версия.
- **Git**: Инициализируйте репозиторий, если это не сделано (`git init`).
- **VS Code Extensions**: Установите `Prettier`, `ESLint` и расширения для работы с Tailwind/MDC (если будут использоваться).

## 2. Технологический стек (AI-Friendly)
- **Frontend**: React (Vite) — обеспечивает быструю разработку и отличную производительность.
- **Styling**: Vanilla CSS (по правилам Antigravity) или Tailwind — для "премиального" вида.
- **Ассеты**: Используйте `generate_image` для создания высококачественных мокапов интерьеров с печатью. Это критично для визуального "WOW-эффекта".

## 3. Подготовка контента
- **Галерея**: Подготовьте список категорий (Природа, Геометрия, Детские, Офисы).
- **Тексты**: Опишите преимущества УФ-печати (не пахнет, моется, не выцветает).
- **Калькулятор**: Согласуйте формулу расчета (цена за м2 + сложность поверхности).

## 4. Рекомендации по SEO
- Заранее определите список ключевых слов (приоритет: "печать на стенах", "роспись стен принтером", "дизайн интерьера [Город]").
- Создайте страницу "Контакты" с правильной разметкой Schema.org.

## 5. Работа с Агентом
- Регулярно обновляйте `PROJECT_CONTEXT.md` при изменении бизнес-задач.
- Используйте `/market_research` для анализа конкурентов перед началом дизайна.
