Этот воркфлоу описывает процесс автоматизированного тестирования для выявления багов на разных устройствах и в разных браузерах.

// turbo-all
1. Установка и настройка окружения Playwright.
2. Создание тестового скрипта `tests/test_site.py` (или .js), который:
   - Эмулирует Desktop (Chrome, Firefox, Webkit/Safari).
   - Эмулирует Mobile (iPhone 14 Pro/Safari, Pixel 7/Chrome).
   - Проверяет:
     - Загрузку Hero-секции.
     - Работу CTA-кнопок (прокрутка к форме).
     - Реактивность и отсутствие перекрытий (layout bugs).
     - Читаемость текста в базе знаний.
3. Запуск тестов на URL: `https://eestruve.github.io/wall-printer/`.
4. Сбор скриншотов всех найденных аномалий.
5. Формирование отчета `bug_report.md` со списком выявленных проблем.
